# Sedona-view — копия

## Как разместить на GitHub Pages

1. **Папка для публикации:**
   - Все собранные файлы лежат в папке `docs/` — именно её использует GitHub Pages.

2. **Пути к ресурсам:**
   - Все пути к CSS, изображениям и другим ресурсам должны быть относительными (например, `css/main.css`, `images/logo.svg`).
   - Внутри SCSS для background-изображений используйте `../images/имя.jpg` (относительно `docs/css/main.css`).

3. **Сборка проекта:**
   - Для генерации актуальных файлов выполните:
     ```sh
     npm run build
     ```
   - После этого все нужные файлы окажутся в `docs/`.

4. **Публикация:**
   - Закоммитьте и отправьте изменения на GitHub.
   - В настройках репозитория выберите публикацию из папки `docs/` (Settings → Pages → Source → docs/).

5. **Открытие сайта:**
   - После публикации сайт будет доступен по адресу: `https://<ваш-логин>.github.io/<имя-репозитория>/`

---

## Важно
- Не используйте абсолютные пути (`/images/...`), только относительные!
- Все изображения, шрифты и CSS должны быть внутри папки `docs/`.
- Если добавляете новые картинки — не забудьте пересобрать проект (`npm run build`).

---

```sh
npm install
npm run build
# Залейте изменения на GitHub
```
